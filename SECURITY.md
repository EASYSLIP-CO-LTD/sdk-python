# Security policy

Use [GitHub private vulnerability reporting](https://github.com/EASYSLIP-CO-LTD/sdk-python/security/advisories/new) to report a suspected vulnerability. Do not open a public issue containing credentials, slip images or personal data.

Include the affected version, a minimal reproduction with synthetic data, and the security impact. We will agree on disclosure after reviewing the report. For account support, use the contact channels at [EasySlip](https://easyslip.com/).

If you cannot use GitHub private reporting, email [hello@easyslip.com](mailto:hello@easyslip.com) to arrange a private report. Do not send credentials or customer slip data in the initial email.
